# Quality checks

## Completed implementation

- Fifteen real static routes plus a custom 404.
- Original MKM logo, authentic supplied hair imagery, real editorial stock photography and self-hosted typography.
- Burgundy umbrella home, teal Care, terracotta Beauty and cobalt Tax pages.
- Separate Care, Beauty, Tax, skincare and home décor routes.
- Service-specific enquiries, topics and an optional local note with no backend collection.
- Responsive 480/960px editorial photos and complete photo source notes.
- Six texture options and nine exact USD length references.
- Quantity 1–10, immediate reference total, query-selected textures and inspiration thumbnails.
- Shop filter, native FAQ disclosure panels and image dialog.
- Working order preview and copy action; valid-number WhatsApp transition.
- Native modal focus containment, Escape close, focus restoration, labelled controls and skip link.
- Dedicated responsive layouts at 700, 860 and 1150px, plus a 359px adjustment.
- Reduced-motion support, no tracked analytics and no external font requests.
- Static build and automated reference, message, asset and link verification.

## Art direction passes

1. Established the full MKM umbrella identity with three distinct service worlds and a photo-led homepage.
2. Refined hero headline width using real font metrics, phone service navigation, image crop ratios, service routing, contact topics and copyable messages. Retained the accurate hair selector and added a dedicated 320px adjustment.
3. Verified the full build, all 540 hair combinations, three service-topic message groups, route/fragment resolution, responsive images, JS imports, alt text and metadata.

## Verification limit

The supported browser-control capability was unavailable in the build environment. No browser automation, responsive screenshots, Lighthouse or assistive-technology session was run. The responsive layout and native-dialog behavior are implemented but need a browser pass before public launch.

## Browser acceptance pass

- View 320, 360, 390, 430, 768, 1280 and 1440px layouts; check horizontal overflow and logo legibility.
- Open/close mobile navigation with touch, Tab and Escape.
- Change all lengths and textures, including query-linked preferences; check totals and quantity bounds.
- Open the message preview, copy it and close by button, Escape and backdrop.
- Confirm focus containment and return to the triggering control.
- Filter the shop and open every route, lookbook image and FAQ.
- Test a confirmed WhatsApp number on phone and desktop without sending a message unintentionally.
- Check console, image loading, reduced motion, contrast and performance on the deployed private preview.
